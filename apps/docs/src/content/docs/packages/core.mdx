## API Reference

### Core Functions

#### `parseUISpec(spec: unknown): CoralNode`

Validates and parses a UI specification against the Coral schema.

```typescript
import { parseUISpec } from '@reallygoodwork/coral-core'

const spec = {
  elementType: 'button',
  name: 'PrimaryButton',
  children: ['Click me'],
  styles: {
    backgroundColor: '#3b82f6',
    color: '#ffffff',
    padding: '12px 24px',
    borderRadius: '6px'
  }
}

const validatedSpec = parseUISpec(spec)
// Returns: CoralNode with validated structure
```

**Parameters:**
- `spec` - Raw specification object to validate

**Returns:** `CoralNode` - Validated Coral specification

**Throws:** Validation error if spec is invalid

#### `transformHTMLToSpec(html: string): CoralRootNode`

Converts HTML markup into a Coral specification.

```typescript
import { transformHTMLToSpec } from '@reallygoodwork/coral-core'

const html = `
<div class="card bg-white p-6 rounded-lg shadow-md">
  <h2 class="text-xl font-bold mb-4">Card Title</h2>
  <p class="text-gray-600">Card description goes here.</p>
  <button class="bg-blue-500 text-white px-4 py-2 rounded mt-4">
    Action Button
  </button>
</div>
`

const coralSpec = transformHTMLToSpec(html)
// Returns: CoralRootNode with component hierarchy
```

**Parameters:**
- `html` - HTML string to transform

**Returns:** `CoralRootNode` - Complete Coral specification

### Schema Management

#### `exportSchemaToJSON(schemaName: string): object`

Exports a specific JSON schema for external use.

```typescript
import { exportSchemaToJSON } from '@reallygoodwork/coral-core'

const coralSchema = exportSchemaToJSON('coral')
const stateSchema = exportSchemaToJSON('state')
const stylesSchema = exportSchemaToJSON('styles')
```

#### `exportAllSchemas(): Record<string, object>`

Exports all available JSON schemas.

```typescript
import { exportAllSchemas } from '@reallygoodwork/coral-core'

const allSchemas = exportAllSchemas()
console.log(Object.keys(allSchemas))
// ['coral', 'state', 'styles', 'variant', 'method', ...]
```

## Advanced Usage

### Custom Validation

```typescript
import { parseUISpec } from '@reallygoodwork/coral-core'

function validateCustomComponent(spec: unknown) {
  try {
    const validatedSpec = parseUISpec(spec)
    
    // Additional custom validation
    if (!validatedSpec.name) {
      throw new Error('Component name is required')
    }
    
    return validatedSpec
  } catch (error) {
    console.error('Validation failed:', error.message)
    throw error
  }
}
```

### Batch Processing

```typescript
import { transformHTMLToSpec } from '@reallygoodwork/coral-core'

async function processHTMLFiles(htmlFiles: string[]) {
  const specs = await Promise.all(
    htmlFiles.map(async (html) => {
      try {
        return transformHTMLToSpec(html)
      } catch (error) {
        console.warn(`Failed to process HTML: ${error.message}`)
        return null
      }
    })
  )
  
  return specs.filter(Boolean)
}
```

### Integration with Build Tools

```typescript
// webpack.config.js
import { transformHTMLToSpec } from '@reallygoodwork/coral-core'

const coralLoader = {
  test: /\.html$/,
  use: {
    loader: 'coral-loader',
    options: {
      transform: transformHTMLToSpec
    }
  }
}
```

## Performance Tips

<Aside type="tip" title="Optimization">
- Cache parsed specifications in production
- Use schema validation during development only
- Implement incremental parsing for large component trees
- Consider using workers for heavy transformations
</Aside>

### Recommended Patterns

```typescript
// Cache validated specs
const specCache = new Map()

function getCachedSpec(key: string, spec: unknown) {
  if (specCache.has(key)) {
    return specCache.get(key)
  }
  
  const validatedSpec = parseUISpec(spec)
  specCache.set(key, validatedSpec)
  return validatedSpec
}
```

## Error Handling

The package provides detailed error messages for debugging:

```typescript
import { parseUISpec } from '@reallygoodwork/coral-core'

try {
  const spec = parseUISpec(invalidSpec)
} catch (error) {
  if (error.name === 'ValidationError') {
    console.error('Schema validation failed:')
    error.errors.forEach(err => {
      console.error(`  - ${err.path}: ${err.message}`)
    })
  }
}
```
