## What is Coral UI?

Coral UI is a comprehensive toolkit for building and transforming UI components in a declarative way. It provides a unified specification format that allows you to convert between different UI representations - from React components to HTML, from design tokens to CSS, and more.

## Quick Example

Here's a simple example of transforming a React component to HTML using Coral UI:

```typescript
import { transformReactComponentToSpec } from '@reallygoodwork/react-to-coral'
import { transformSpecToHTML } from '@reallygoodwork/coral-to-html'

// React component source
const reactSource = `
function Button({ children, variant = 'primary' }) {
  return (
    <button className={\`btn btn-\${variant}\`}>
      {children}
    </button>
  )
}
`

// Transform React to Coral spec
const coralSpec = transformReactComponentToSpec(reactSource)

// Transform Coral spec to HTML
const html = transformSpecToHTML(coralSpec)
```
