## What is Coral UI?

Coral UI is a comprehensive toolkit that enables seamless transformation between different UI representations. Whether you're working with React components, HTML markup, design tokens, or CSS styles, Coral UI provides the tools to convert between these formats using a standardized specification.

## Your First Transformation

Let's start with a simple example that demonstrates the core concept of Coral UI - transforming a UI specification.

### 1. Create a Basic Coral Spec

```typescript
import { parseUISpec } from '@reallygoodwork/coral-core'

const buttonSpec = {
  elementType: 'button',
  name: 'PrimaryButton',
  children: ['Click me'],
  styles: {
    backgroundColor: '#3b82f6',
    color: '#ffffff',
    padding: '12px 24px',
    borderRadius: '6px',
    border: 'none',
    cursor: 'pointer'
  },
  attributes: {
    type: 'button'
  }
}

// Validate and parse the specification
const validatedSpec = parseUISpec(buttonSpec)
console.log('Valid spec:', validatedSpec)
```

### 2. Transform HTML to Coral Spec

```typescript
import { transformHTMLToSpec } from '@reallygoodwork/coral-core'

const htmlString = `
  <div class="card bg-white shadow-lg rounded-lg p-6">
    <h2 class="text-xl font-bold mb-4">Card Title</h2>
    <p class="text-gray-600">Card content goes here.</p>
    <button class="btn btn-primary mt-4">Action</button>
  </div>
`

const coralSpec = transformHTMLToSpec(htmlString)
console.log('Coral spec from HTML:', coralSpec)
```

### 3. Convert Tailwind to CSS

```typescript
import { tailwindToCSS } from '@reallygoodwork/tw2css'

const tailwindClasses = 'bg-blue-500 text-white px-4 py-2 rounded-md hover:bg-blue-600'
const cssStyles = tailwindToCSS(tailwindClasses)

console.log('CSS styles:', cssStyles)
// Output: {
//   backgroundColor: '#3b82f6',
//   color: '#ffffff',
//   paddingLeft: '16px',
//   paddingRight: '16px',
//   paddingTop: '8px',
//   paddingBottom: '8px',
//   borderRadius: '6px'
// }
```

## Understanding the Coral Specification

The Coral specification is a JSON-based format that describes UI components in a framework-agnostic way. Here's the basic structure:

```typescript
interface CoralNode {
  elementType: string        // HTML element or component name
  name?: string             // Component name
  children?: (CoralNode | string)[]  // Child elements or text content
  styles?: Record<string, any>       // CSS styles
  attributes?: Record<string, any>   // HTML attributes
  props?: Record<string, any>        // Component props
  variants?: CoralVariantType[]      // Style variants
  state?: CoralStateType[]           // State management
  methods?: CoralMethodType[]        // Component methods
  imports?: CoralImportType[]        // Import dependencies
}
```
