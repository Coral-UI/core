# Coral Figma Plugin

This is the BETA version of the Coral Figma plugin. It is not yet ready for production.
But you can certainly test it!

Playground: [https://beta.coral.design](https://beta.coral.design)

## Installation

- In Figma, open `Plugins > Development > Import Plugin from manifest.json` and select the `manifest.json` file in this directory.
- Search for `Coral` in the plugin list to open it up.
